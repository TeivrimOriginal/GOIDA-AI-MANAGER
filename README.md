# GOIDA AI MANAGER

Local AI Chat with Ollama backend. Pure C++ WinAPI application.

## Architecture

- **launcher.cpp** - Full launcher: settings, training panel, model management, auto-messaging, tray notifications, config save/load
- **client.cpp** - Clean release client: just chat with configured persona, reads config.ini
- **config.ini** - Shared config file (auto-generated by launcher)

## Requirements

- Windows with MinGW g++
- Ollama running on localhost:11434

## Build

```bash
# Launcher (full settings + training)
g++ -std=c++17 -O2 -mwindows -municode -o launcher.exe launcher.cpp -lws2_32 -lcomctl32 -lshell32

# Client (chat only, reads config.ini)
g++ -std=c++17 -O2 -mwindows -municode -o client.exe client.cpp -lws2_32 -lcomctl32 -lshell32

# Prompt generator
g++ -std=c++17 -O2 -o train_prompt.exe train_prompt.cpp
```

## Usage

1. Start Ollama: `ollama serve`
2. Pull a model: `ollama pull qwen2.5-coder:3b`
3. Run **launcher.exe** to configure: set name, model, system prompt, temperature, training examples
4. Launcher saves config.ini on exit
5. Run **client.exe** for clean chat (reads config.ini automatically)
